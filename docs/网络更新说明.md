# 1.0.1 网络与失败状态更新

本次更新针对真实API出现的Windows连接超时，以及条件更新失败后仍能执行旧条件的问题。

- 建立连接超时10秒；仅ConnectError/ConnectTimeout最多尝试两次。每次尝试独立计入model_calls并保存阶段，不伪造Token用量。
- 等待响应超时、HTTP错误、输出错误不自动重发。保持HTTPX默认代理行为，不擅自关闭系统/环境代理。
- 条件更新失败会保留原条件用于查看，但暂停执行；网页按钮与/run同时受保护。
- 成功补充明确条件、手动应用有效条件或/new可以恢复相应状态；空修改和无效表单不能解除暂停。
- 错误提示指出连接/响应阶段。诊断入口为 `python diagnose_api.py --api`，不输出Key、完整.env或代理凭证。
- --api会发送简短真实请求，产生少量Token；不带--api仅检查主机、DNS与直连TCP。
- 修正一处测试文件在Windows上读取UTF-8 JSON时的编码声明。

## 应用更新

1. 在运行Streamlit的终端按Ctrl+C停止服务。
2. 将更新包内容解压到项目根目录，覆盖对应文件。
3. 无需重建数据库或重装依赖，重新启动：

```powershell
.\.venv\Scripts\python.exe -m streamlit run .\app.py
```

4. 刷新浏览器。新进程会新建会话；之前的分析证据仍保存在reports目录。

API恢复并不表示所有网络故障已永久解决。本次用户已经验证test_api.py返回HTTP200、手动统计结果符合参考；此更新提供有限重试及失败保护，不将网络问题伪装成统计成功。
