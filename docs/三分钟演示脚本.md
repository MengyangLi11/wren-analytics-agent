# 三分钟演示脚本

提前启动 Streamlit 并打开数据与证据页。演示使用本机密钥，录屏只展示应用与终端结果，不打开 `.env`。API 暂不可用时展示手动工具路径，并明确该段没有验证自然语言理解。

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00–0:25 | 展示项目首页、数据范围 | 54.19 万原始行、53.64 万纳入发票行；GBP 开票口径，取消不等于到账退款 |
| 0:25–0:55 | 输入“收入多少”，补充净开票金额和 2011 年 11 月 | 歧义追问、条件继承；模型提取条件，用户确认后执行 |
| 0:55–1:25 | 执行汇总，打开 SQL、契约与指纹 | 1,432,731.70 GBP，数据库完整聚合，计算与证据有明确来源 |
| 1:25–1:50 | 查看原始行追溯；修改、取消一项筛选 | Excel 行号与分类理由，修改字段保留其他条件 |
| 1:50–2:25 | 切换 2011 年 11 月均值区间 | 2,642 发票、1,660 客户簇、均值约 432.30 GBP；客户簇 Bootstrap 的样本和假设 |
| 2:25–2:45 | 下载 JSON，用 verify_report.py 重算 | 固定快照和类型化参数重算，不执行任意证据 SQL |
| 2:45–3:00 | 展示已有验收记录 | 50 条回归和新 20 条措辞通过；说明测试范围及用量代价 |

重算命令中的文件名使用实际下载的证据，不能原样使用占位符：

```powershell
.\.venv\Scripts\python.exe .\verify_report.py .\reports\sessions\实际文件名.json
```

最终保存一段连续录屏及 2–3 张截图。不要把预录结果当作现场 API 输出；演示中的金额由当前工具运行产生。
