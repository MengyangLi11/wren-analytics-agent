# 简历项目条目

**可核验零售数据分析 Agent｜个人项目｜2026.11**

技术栈：Python、SQL、Wren Engine、LangGraph、Qwen Function Calling、DuckDB、Streamlit。

项目链接：https://github.com/MengyangLi11/wren-analytics-agent

- 基于 Wren Engine、LangGraph 与 Qwen Function Calling 构建零售分析 Agent，接入 UCI 原始 54.19 万行开票记录；通过指标契约、多轮条件管理及只读 SQL 聚合，实现业务口径追溯、Excel 行号定位与 JSON 证据重算。
- 设计逐行 Decimal 舍入与数据库汇总对账，按不同分析任务区分客户信息缺失记录的纳入规则；实现以客户为簇的 Bootstrap，输出发票金额均值、区间及样本排除说明。
- 建立独立 Excel/Decimal 参考与分层评测，任务路由修复后原 50 条真实 API 回归由 46/50 提升至 50/50；新增 20 条措辞检查全部通过，该轮平均 909 Token/题、2.37 秒/题。

## 使用边界

以上结果对应固定任务集与一次实测，不是生产通用准确率。旧 50 条题目已用于调试；同集 Token 总量增加约 14.8%，面试时如实说明。本项目基于开源组件扩展，未宣称上游 PR、模型微调或 RAG。

面试前应能独立解释代码及关键设计，并实际操作一遍数据构建、条件修改、证据查看与重算。简历无需把所有技术名词塞入项目标题。
