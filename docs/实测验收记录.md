## 与修复前比较

v1.0.1 原 50 题真实 API 初测为 46/50（92%），总计 39,522 Token、97.799 秒。v1.0.2 同集回归为 50/50，总计 45,354 Token、116.976 秒。

通过比例提高 8 个百分点，Token 总量增加 5,832（约 14.8%）。未测量实际费用，不能把总 Token 变化直接等同账单变化；也不能声称此次修复同时降低成本或延迟。

原 50 题已全部用于调试；新 20 题只是已知能力边界内的改写措辞，不覆盖任意业务、任意数据库和任意统计任务。若后续针对新集失败调试，其复跑同样按回归登记。
